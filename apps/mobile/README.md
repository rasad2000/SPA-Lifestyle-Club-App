# @spa/mobile: SPA Garden Club app (Expo SDK 58)

German-language, light-only lifestyle client for the club's feed/course server (`apps/server`, port 8790).
Wire format: `@spa/contract` (`packages/contract`).

```bash
npm run server            # from the workspace root: API on :8790
npx expo start            # this dir: dev server (Expo Go / dev build / web)
npx expo export -p web    # → dist/, served by the API server as an SPA
```

## Layout

| Path | What |
| --- | --- |
| `src/app/` | Routes only. `_layout.tsx` draws the hall and hosts NativeTabs (Home / Mitglieder / Signale), each tab its own Stack. |
| `src/api/` | Base-URL resolution, contract-validated fetch, live WebSocket, offline cache, pure feed/thread merge reducers. |
| `src/hooks/` | `useChannels`, `useChannelFeed`, `usePostThread`, `useCourses`, `useCourse`, `useHealth`. |
| `src/ui/` | Theme tokens, `Glass` primitive (Liquid Glass → blur → tinted → solid), the frame, text, icons, states. |
| `src/components/` | Home cards and pages, feed cards, signal card, course cards, lesson blocks, live indicator, tab bars (native + web). |
| `src/content/` | The fictional Home and Mitglieder content. |
| `src/i18n/de.ts` | Every user-visible string. |

## Server URL

First hit wins: `EXPO_PUBLIC_API_URL` → (web) same origin → (dev) Expo `hostUri` host + `:8790` →
`http://127.0.0.1:8790`.

For a physical phone, install the current SDK 58 Expo Go app and run `npx expo start --host lan`.
The phone and workstation must share a Wi-Fi network, the API must listen on `0.0.0.0`, and the
firewall must allow ports `8081` (Metro) and `8790` (API). Scan the QR code with the iPhone camera
or from inside Expo Go on Android. See [Running the demo](../../docs/demo.md) for troubleshooting.

## Config / release

`app.config.ts` reads `SPA_IOS_BUNDLE_ID` / `SPA_ANDROID_PACKAGE` (default `club.spa.garden` is a
PLACEHOLDER: fix it before the first TestFlight upload; a bundle id is permanent) and
`SPA_EAS_PROJECT_ID`. `eas.json` has development / preview / production profiles. Before
`eas submit`, add `submit.production.ios.ascAppId` (the App Store Connect app id).

Icons, splash and every other image are generated by `tools/make_brand.py` (workspace root).
